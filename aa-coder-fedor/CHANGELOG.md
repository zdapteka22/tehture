# Changelog

## Unreleased

- Установщик снова тихий: окно прогресса без слайдов оплаты, один ярлык на своём рабочем столе, при сбое запуска файлы и ярлык не сносятся.
- Навык опыта на все инструменты: браузер, ПК, код, человек, задача. Победителя поднимает, промах оставляет уроком, ничего из журнала не удаляет. Быстрый поиск — MiniSearch.
- Клик в SPA: если URL не сменился, это меню/аккордеон — не качаем другой движок и не долбим ту же кнопку. Жмём появившийся пункт или Enter.

## 2026-09-22 — предохранитель из исходников кодера

- guard.cjs: неизвестный инструмент, «готово» без доказательства, слепой клик, остановка без причины.
- Команды hub: guard и goal (goal-brain / loop-guard). Клики JS+CDP и оплата не откатывались.

## 2026-09-22 — клик по кнопкам в браузере

- Если клик не попадает, кодер сам меняет набор: JS-клик, CDP-мышь, Playwright locator / JS / mouse.
- Нерабочий скачанный набор удаляется. Из белого списка можно поставить puppeteer-core или Chromium.
- Инструмент click_kit: status / heal. Не просит человека нажать кнопку.

## 2026-09-22 — приём оплаты и готовность к продаже

- ЮMoney / ЮKassa: счёт, ссылка оплаты, проверка по API и HTTP-уведомлению.
- Крипта USDT / BTC / TON: уникальная сумма, проверка по обозревателю, повторно тот же tx не принимается.
- Настройки → Приём оплаты. Секреты в pay.json / env, не в исходниках.
- Лог сбоев: %LOCALAPPDATA%\\Fedor2\\logs\\fedor-error.log
- Лицензионное соглашение 3.0 в настройках и EULA.txt
- Версия релиза: 3.0.paid/free + дата. `npm test` — обязательный прогон перед упаковкой.

## 2026-09-22 — платная 3.0 для продажи

- Включена платная SKU: тарифы, paywall, лимиты помощника 4 / 10 / без лимита.
- Внутри тот же кодер, что и бесплатный: браузер не встаёт сам, Build Harness, оператор, локальная модель.

## 2026-09-22 — Build Harness в кодере

- Build Harness встроен в Fedor: inspect / apply / check / changelog / version / pack.
- В браузере кодер не встаёт после нескольких кликов — только по результату, стоп или отказу системы.
